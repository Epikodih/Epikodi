# Journal des décisions d'architecture (ADR)

Chaque décision structurante est consignée dans un fichier `NNNN-titre.md` : contexte, options, choix retenu, conséquences. Une décision acceptée n'est jamais réécrite : si elle change, on crée un nouvel ADR qui la remplace.

| N° | Décision | Statut |
|---|---|---|
| [0001](0001-moteur-de-lecture.md) | Moteur de lecture de l'app TV : media_kit (libmpv) | accepté |

## Modèle

```markdown
# ADR NNNN : titre

- **Statut** : proposé | accepté | remplacé par NNNN
- **Date** : AAAA-MM-JJ
- **Issue** : #

## Contexte
## Options étudiées
## Décision
## Conséquences
```
